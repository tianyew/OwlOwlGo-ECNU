# 项目管理

- [project-plan.md](project-plan.md)：课程进度、里程碑、工作项与现有风险记录。
- 沟通管理计划：在课程对应阶段补充 `communication_mgmt_plan.md`，明确渠道、频率、参与人和决策记录方式。
- 风险管理计划：在课程对应阶段补充 `risk_mgmt_plan.md`，明确风险识别、评审和应对规则；当前风险清单保存在项目计划中。

具体任务与缺陷使用 GitHub Issues/Projects 跟踪，会议讨论使用 Wiki。正式计划保存在本目录，迭代结果与经验放在 [retrospection/](../retrospection/README.md)。
