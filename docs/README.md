# Project documentation

该目录只保存需要与代码版本对应的正式项目文档。

- `project-plan.md`：课程阶段、分工、工作项和风险；
- `requirements/problem_definition.md`：工程问题的 5W1H、痛点映射和产品描述；
- `requirements/functional_spec.md`：系统角色、功能树、功能需求、业务规则、领域模型和验收标准；
- `requirements/nonfunctional_spec.md`：性能、可靠性、安全、隐私、AI 质量和发布质量门；
- `adr/`：重要架构决策及其背景、选择和影响。

会议纪要、FAQ、课堂讨论和学习资料更适合存放在 GitHub Wiki。详细需求和方案将在评审确认后再按课程进度纳入版本库。
