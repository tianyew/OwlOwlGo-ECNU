# ADR-0001：汉语学习网页采用模块化单体

- 日期：2026-10-15
- 状态：采纳

## 背景

项目从英语学习转向成年初学者的汉语学习，当前用户要求先搭建架构与产品设计，业务功能后续细化。现有 Vue/FastAPI 技术基础可以复用，声调、字形与文化资源需要独立内容模型和适配边界。

## 决策

1. 保留响应式网页形态与 Vue 3 + TypeScript / FastAPI 技术栈，采用模块化单体。
2. 前端按档案、测评、拼音声调、汉字、情境、文化、复习、进度划分模块。
3. 后端将领域规则、应用编排、API、存储与外部服务适配分离；领域层不依赖 Web 或数据库。
4. 声调与识字维护分维度学习状态；文化卡与语言任务关联；资源记录来源、许可、审核和版本。
5. 当前仅实现静态入口与目录占位；业务 API、数据库迁移与具体算法待后续迭代。

## 备选与影响

暂不拆微服务，减少初期部署和跨服务事务成本。以后若语音分析出现独立计算需求，可沿既定适配边界拆分。原生 App、支付和外部模型供应商选型留到需求验证后决定。
