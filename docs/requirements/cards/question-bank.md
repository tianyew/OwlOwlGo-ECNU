## 功能到底是干什么的

让团队成员把准备好的HSK题目文件上传到系统；系统先指出缺字段、错误答案、缺音频、重复题等问题。内容审核人再逐题检查等级、考点和答案，审核通过后发布。学习者开始前测、单元小测或后测时，系统从已发布题目中抽取符合要求的题，并保存本次试卷；刷新后仍是同一份题。

例如：上传一个含N道题的文件，系统发现a道缺解析、b道重复。上传者先下载错误清单并修正；全部格式检查通过后确认导入“待审核”区。审核者退回不合格题，批准其余题。只有批准且发布的题能被新测验使用；“文件上传成功”不等于“题库建设完成”。

## “符合HSK标准”怎样判断

HSK官方站提供大纲与样题入口，并说明新版大纲包含任务、话题、词汇、语法、汉字五部分。题库应按明确的大纲版本核对内容，不能混用不同版本的等级标签。[官方HSK介绍与大纲入口](https://www.chinesetest.cn/HSK)

官方公告列明HSK3.0全球正式开考日期为2026年12月13日；旧资源中心也保留既有大纲和样题，因此必须记录材料版本，而不能仅根据下载日期判断版本。[官方公告](https://old.chinesetest.cn/gonewcontent.do?flag=kdnew&id=51336883)、[官方资源中心](https://admin.chinesetest.cn/godownload.do)

每道题审核至少确认：

1. 写明大纲版本、目标等级、技能/题型、考点，以及大纲条目或页码依据；不能仅填“HSK”。
2. 题干用语、词汇/语法难度与目标一致；正确答案可确定，干扰项与解析合理。
3. 听力题有可播放音频；图片题有清晰图片；材料题的题干、子题和选项引用完整。
4. 记录原创/授权来源及可使用依据；公开可下载不自动等于可以复制并对外发布。AI生成题必须走相同审核流程。
5. 教学主题与HSK考点分别标注。“古诗入门”等项目内容不能仅凭主题名称标为HSK题；不符合者可保留为项目扩展内容，但不计入HSK题库。

本系统的分项练习/诊断不能自动称为官方HSK全真考试。团队若要做完整模拟卷，必须另明确该版本的完整题型、题量、时长和评分结构，并实现对应能力；未覆盖的技能在结果中明确标明未测。

## Q-A · 给题库建立数据库和管理权限 — 管佳欣

**用途：** 让上传的题、审核意见和历史版本能保存下来，同时阻止普通学习者读取答案或修改题库。

- 建立题目及版本、素材、导入批次、审核记录、发布版本、组卷规则、测验实例的存储基础；A负责共同表契约和迁移基础，C/E/D分别实现各自业务读写。
- 区分学习者、上传者、审核者、发布者；同一个人可有多个角色，但不能审核自己提交的题。身份从服务器会话读取，注册表单不能自行勾选管理员。
- 服务器按接口逐项检查权限；隐藏按钮不是权限校验。普通用户不能通过猜地址下载含答案的上传文件。
- 发布后修改题目必须创建新版本，原来已交卷的内容、答案和评分记录不随题库修改而改变。

**验收：** 普通账号调用导入/审核/发布接口均被拒；重启数据库仍能找到题目和审核记录；修改一道已发布题后，旧报告仍显示原题原结果。

## Q-B · 按HSK依据准备可上传的题库 — 钱俊

- 为前测、单元小测、后测设计各自组卷规则：需要测什么、抽多少题、覆盖哪些考点、采用何种评分与通过条件。旧8/2/10题和60分规则不能自动当作HSK标准。

## Q-C · 上传题库，查看问题后确认导入 — 黄云舒

**用途：** 成员通过页面上传题目，不必开发者修改源码或直接写数据库。

1. 下载UTF-8 CSV模板及素材说明；一行一个可评分题项。可同时上传ZIP素材包，表中引用包内相对路径。首版不做PDF/Word自动识题；此类原始资料由成员整理为模板。
2. 选择文件后点击“检查文件”；显示上传/处理中/完成/失败。服务器返回批次号，页面重新打开可按批次号查询，不能因刷新重复导入。
3. 预览总题数、可导入数、错误数、重复数和素材缺失数；逐行显示问题，例如“第23行：正确答案不在选项中”。允许下载错误清单。
4. 有错误或未处理重复题时禁用“确认导入”；修正后重新检查。完全相同的文件提示已有批次，可打开原批次；不能静默覆盖已发布题。
5. 全部检查通过，点“确认导入”后整批写入待审核区，显示“已导入N题，待内容审核”。事务失败整批不生效；不因导入成功自动发布。

**验收：** 正常文件成功入待审核；混入缺解析/错误答案/缺音频/重复题时逐行提示且不能发布；重复确认不多插题；超限文件明确拒绝；真实批量任务能查状态和错误报告。

## Q-E · 衔接AI候选生成，审核、发布和管理题库 — 郑仲佑

**用途：** 接收人工上传和AI生成两种来源的候选题，经非作者审核后发布。郑仲佑同时负责[P-E05](e-郑仲佑.md#p-e05)的AI生成入口和API调用，钱俊提供HSK标准支持并参与非作者审核。

新增“题库管理→AI生成候选题”：填写已登记标准、等级、考点、题型和本批数量，点生成后预览题干、答案、解析和问题清单；可编辑/丢弃，校验通过且素材齐全后明确送审。生成时只存草稿，不能直接发布或计入题库达标数量。接口见[N09](contracts.md)。生成者不能审核自己的题，不能因为是系统生成而跳过作者限制。

统一购买API，各业务负责人接入自己的生成调用；不新建公共模型调用基础任务。

- 待审核列表按批次、大纲版本、等级、技能、题型筛选，详情按学习者实际样式预览题目、音频和图片，同时向审核者显示答案、解析和依据。
- 审核者逐题确认内容，选择“通过”或填写原因“退回修改”；作者不能自审。修改后生成待审版本，不覆盖已发布版本。
- 发布者选择已通过且素材/题型能力齐全的题，确认发布；未审/退回题不能发布。批量发布可以有，不能用“一键自动审核”代替内容核对。
- 已发布题可停用，必须写原因；新组卷不能选入。已提交报告保留快照；进行中试卷若含停用题，暂停提交并提示重新开始，保留原草稿与取消原因，不暗中替换题目。
- 按团队覆盖矩阵展示有效数量和缺口，统计全库去重题项，不把选项改序、跨用途引用或重复导入算新题。

**验收：** 未审题不能被抽到；非作者审核后可发布；停用后新卷排除它；旧成绩可追溯；导出统计与数据库发布记录一致。

## Q-D · 从已发布题库组卷，刷新后继续同一份题 — 周子涵

**用途：** 前测、小测和后测使用持续扩充的题库，学习者不再反复遇到一套写在代码里的固定题。

1. 用户点“开始测验”时，服务端按用途、已发布规则和目标范围组卷，只选已发布且未停用、素材可用的题；生成本人的测验实例。题型不支持、规则缺失、配额不足则说明缺什么，不能用旧固定题凑卷。
2. 保存题目版本、顺序、选项顺序、材料组关系、评分规则版本与用途。刷新和“继续测验”读取原实例；重新开始才生成新实例。
3. 前端显示实际题数N、已答n题、分页和本次测量范围；读取公开题目不含正确答案/解析、音频文字稿等解题信息。听力及图片按题型展示。未实现的答题/评分类型不能被发布规则选入。
4. 答案和草稿绑定测验实例；交卷按实例冻结的题目/评分判定，校验不能提交卷外题；全部必答题已答才允许提交。需要人工评分的类型若纳入范围，结果先显示待评分，完成审核评分前不生成最终诊断或通过记录。
5. 新试卷按已确定的避重复政策组卷，并保存执行结果。前后测可采用不同题但相同的覆盖和难度设计；未经等值验证不把分差解释成正式HSK等级提升。
6. 将实例ID、标准版本、测量范围、实际总题数及题目快照交给B诊断和E报告/复习；报告查历史快照，不查已被更新的当前答案。

**验收：** 更换已发布题库无需改前端即可出现新题；不同规则的题数正确；刷新不换题；断网重试交卷只记一次；未发布题/卷外题不能提交；题库不足有明确错误而非降级回固定题。

## 上传字段与校验约定

| 字段 | 内容及校验 |
| --- | --- |
| external_id、version | 来源内稳定ID与正整数版本；新批次不能静默覆盖同ID不同内容 |
| standard_id、level、skill、question_type | 已登记的大纲版本与合法等级/技能/题型；可用枚举由标准登记及系统能力决定 |
| syllabus_reference、knowledge_points | 大纲条目/页码依据和知识点列表，不能为空；标签真实性仍须人工审核 |
| prompt、options_json、answer_json、explanation | 题干、结构化选项、答案、解析；按题型校验。单选答案恰好一个且存在于选项中；其他题型按已登记schema校验 |
| material_id、part_id、material_order | 材料/子题关系；成组抽取时不得拆断；统计按可评分题项计数，不按素材数量计数 |
| audio_path、image_paths_json、transcript | 按题型要求提供素材；音频稿为受保护字段，不随未提交公开题下发 |
| source、usage_basis、author | 来源与可使用依据、作者；服务端保存实际上传人身份，不能以作者文本代替权限身份 |
| topic_ids、unit_ids、allowed_uses | 项目课程关联与允许用途；不匹配课程的题不能硬塞进该单元小测 |

客户端预检改善提示，服务器仍须完整校验。ZIP只接受受限类型和配置大小，禁止绝对路径/上级目录跳转，限制解压后体积；CSV导出的错误文本不得作为表格公式执行。相同题目/答案及素材指纹命中标重复，近似重复交人工检查；跨批次、跨版本维护来源题ID便于画像去重。素材齐全和版权依据齐全才进入审核。

## 接口交接（新增建议，尚未实现）

- 管理前缀`/api/v1/content`：`GET /question-template`；`POST /imports`（multipart题目CSV＋可选素材ZIP＋request_id）→202批次ID；`GET /imports/{id}`查校验进度/摘要；`GET /imports/{id}/errors`下载问题；`POST /imports/{id}/confirm`→待审题。确认仅允许校验全通过的不可变文件摘要。
- `GET /questions`按版本/等级/状态筛选并分页；`GET /questions/{id}/versions/{version}`管理详情；`POST /questions/{id}/versions/{version}/review`（结论、原因、expected_version）；`POST /releases`发布选定已审版本；`POST /questions/{id}/disable`停用并记录原因；`GET /coverage`返回发布去重统计。
- 上传者读自己批次并修改退回草稿；审核者读待审内容并审核非本人内容；发布者发布/停用；角色可组合但不能绕过自审限制。401未登录、403无角色权限、404资源不存在、409版本/重复请求冲突、422校验/数量不足、413超限、503服务不可用。
- 学习前缀：`POST /quiz-attempts`（用途quiz_id、蓝图ID/版本、request_id）→实例和公开题；已有未完成实例返回原实例或要求明确取消，不隐式重抽。服务端验证该用户可用规则，不接受任意等级/课程权限。
- `GET /quiz-attempts/{id}`；`PUT /quiz-attempts/{id}/draft`（revision、题目ID及类型化答案、当前页）；`POST /quiz-attempts/{id}/submissions`（submission_id、revision、answers）→结果及进度。ID同内容重放返回同一结果，异内容409；只允许本人访问。
- 原K04保留旧固定卷/历史兼容；新卷使用上述实例接口，不把动态答案硬塞进仅支持selected_index的旧契约。K03首页进度增加当前实例摘要和实际题数；新草稿由实例接口保存，不能被旧整包progress覆盖。N02/N07/N06增加实例、标准/规则版本及稳定来源题ID；N04提示练习绑定其独立题目版本，不能读取正在测验的答案。

所有接口按模块负责人实现并在同一契约下联调。Q-A只负责基础与公共约束，不代写C上传、E审核和D组卷全部代码。

## 分工和进度影响

新增题库管理、素材、组卷与数据版本会增加工程量，原三周安排须重新估算，不再承诺沿用原时间完成。五人各负责一个新增包；B/E重点把握教育标准和内容审核，A/C/D承担存储、上传及出题工程。内容整理按团队确定的题量分批分给五人，作者与复核人分离；每批完成后看实际耗时再调整，不能只用卡片张数认定工作量相等。
