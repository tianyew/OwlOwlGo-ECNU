# 中文学习空间：前端界面设计

本轮围绕「找到下一步学习任务 → 阅读课程 → 作答 → 查看反馈」组织页面，
沿用 Vue 3 和现有学习接口，不增加运行依赖。

## 界面设计

| 区域 | 内容与目的 |
| --- | --- |
| 顶部 | 品牌、账号与登录入口，保持身份可见 |
| 左侧导航 | 首页、我的学习、学习方向、学习画像；当前页面明确高亮 |
| 任务区顶部 | 当前位置与持续可见的进度保存状态 |
| 首次学习首页 | 一个主要设置入口、三步引导和四方向内容预览 |
| 已设置首页 | 下一单元与真实进度置顶；学习路径为主，前测、方向与画像集中在概览卡片 |
| 课程与测验 | 课程目标、词句、情境对话、练习与测验依次呈现 |
| 画像 | 实际证据矩阵，区分未测评与已有测评数据 |

小于等于 1000px 时首页学习路径与概览上下排列；小于等于 900px 时左侧导航转为横向导航；小于等于 600px 时主内容与概览卡片单列呈现。
方向预览保留双列，方向选择表单改为单列；能力矩阵在自身容器内滚动。

## 视觉设计

- 使用白色、蓝色和灰色：主色 `#0071e3`，背景 `#f7f8fa`，白色内容卡片，浅蓝 `#edf6ff` 承载学习引导与选中状态。
- 保存成功与常规状态使用蓝色；答题正确、等待、错误保留少量语义色，并配合文字说明，避免仅靠颜色识别。
- 标题、正文、辅助文字分层，中文使用本地系统字体；汉字插画仅用 HTML/CSS，无远程字体或图片请求。
- 借鉴多邻国的清晰层级与轻松感：圆角卡片使用 2px 描边，按钮采用实色底边和按压反馈；图标由 `AppIcon.vue` 提供一致的线性 SVG。
- 登录、首页、导航、方向选择、课程、测验与报告共用 `src/styles/learning-theme.css`，在基础样式后加载，统一颜色、形状与交互反馈。
- 首页学习路径用勾选、播放和书本节点区分已完成、下一课与其他单元，搭配文字状态；全部单元均可打开，不增加锁关、积分或连续学习天数。
- 选择题采用描边选项卡与字母标识，选中、正确、错误沿用真实作答状态；保留原生单选输入的键盘操作。
- 课程对话采用左右对齐气泡，突出情境中的表达关系。

### 文案密度

- 去掉英文装饰标签、重复标语、页脚口号和重复的卡片说明，保留教学内容中的拼音与题目辅助文字。
- 首页以标题、学习任务和操作按钮为主；预计用时、恢复进度采用一条集中信息展示。
- 学习安排、作答规则和画像统计口径放入原生可展开说明，支持键盘操作。
- 画像提交数、不同题目数和重复练习数改为数据卡片；未测评格子显示「—」，含义由表格说明统一解释。
- 次级说明通常使用 13–14px；保存状态、失败原因、游客权限及提交条件在相关操作处直接可见。
- 登录页省去重复输入提示；注册页保留账号格式和密码长度要求。

## 反馈与容错

| 状态 | 页面行为 |
| --- | --- |
| 加载 | 学习空间加载提示与骨架占位；题目加载提示 |
| 空内容 | 无正式作答时解释画像为空的原因，未测评保留「—」 |
| 保存中 | 持续显示正在保存；正式提交沿用原有保存锁 |
| 成功 | 显示进度已保存，成绩与完成状态来自后端响应 |
| 前置条件未满足 | 方向入口提示先完成前测；游客可以浏览但不能正式作答或查看个人画像 |
| 失败 | 保留已选答案，显示保存或加载失败及重试操作；冲突继续要求加载最新进度 |

前后测提供题号导航、当前题标识、已答标识与进度条。全部题目作答后才可提交；
正确答案与解析仍只在正式提交后展示。草稿数量在首页使用「已作答」表述，不误称为已提交。

提供跳到主要内容链接、语义导航、键盘焦点、状态播报，以及减少动态效果偏好支持。

## 小鸮 AI 伴学交互示例

学习空间右下角新增蓝白色小猫头鹰浮球，点击打开伴学面板。
头像使用本地 SVG，不加载外部图片；桌面显示浮动面板，手机宽度下使用底部面板布局。
猫头鹰有轻微挥翅和眨眼动画，并遵循减少动态效果偏好。

当前为**交互示例，预设回复，尚未连接真实 AI**，面板持续标明这一状态。

| 场景 | 示例交互 |
| --- | --- |
| 单元课程 | 引用当前单元已有句型和例句，展示课程答疑 |
| 测验作答 | 跟随当前题目，演示三步观察提示，提交前不展示答案复盘 |
| 提交后复盘 | 引用服务端已返回的实际选择、正确答案和解析 |
| 学习画像 | 根据已有题目数、重复次数和待巩固项展示解读，不生成新的能力分数 |

支持快捷提问、文本输入、Enter 发送、Shift+Enter 换行、Esc 收起与清空对话。
中文输入法组词时按 Enter 不会误发送。面板由用户主动打开，收起后焦点回到浮球。
切换页面或题目会更新上下文并清空当前示例对话；刷新或切换账号也不会保留对话。

伴学示例不新增后端接口、不调用模型，也不额外写入作答、成绩、画像或提示使用记录。
接入真实辅导能力时，需补充服务端上下文校验、帮助记录和模型调用。

实现位于 `code/frontend/src/features/companion/`：

- `StudyCompanion.vue`：浮球、面板和对话交互。
- `OwlAvatar.vue`：猫头鹰头像与轻动画。
- `demo.ts`：只读上下文类型和预设回复。

`LearningJourney.vue` 提供当前课程、题目和已有作答证据；测验组件只上报题目元信息及提交状态。

试用步骤：

1. 打开学习空间，登录或选择游客体验。
2. 点击右下角「AI 伴学」，尝试快捷提问或输入问题。
3. 进入单元页，点击「讲讲本课句型」；在前测中切换题号，点击「给我一点提示」。
4. 登录后进入已有作答的画像页，点击「解读我的画像」。

桌面 Chrome 已查看浮球、面板、快捷回复和前测题目上下文；使用游客模式，未提交正式作答。
手机布局已编写响应式样式，手机实机视觉与软键盘适配仍需人工验收。
