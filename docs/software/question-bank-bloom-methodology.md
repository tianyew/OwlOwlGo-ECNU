# 题库的修订版布鲁姆分类与 AI 辅助审核方法

## 1. 研究目的

本项目将 700 篇阅读材料及其 2,090 道小题作为成人二语汉语学习系统的候选内容资源。为支持按学习者水平、学习主题和认知目标进行检索及自动出题，项目在保留原始题库的基础上，为材料和题目增加二语难度候选、主题、题型、语言能力维度、认知过程、学习支架、审核状态与授权状态等字段。

新增字段不修改原始题干、答案和来源信息。原始中小学年级仅作为文本复杂度线索，不直接等同于 HSK、CEFR 或成人二语能力等级。

## 2. 理论框架

认知过程标注采用 Anderson 和 Krathwohl 对布鲁姆教育目标分类学的修订版，将认知过程划分为记忆、理解、应用、分析、评价和创造六类。分类对象是题目要求学习者执行的主要可观察认知操作，而不是对学习者总体能力或题目绝对难度的判断。

语言能力与认知过程分别建模。例如，“翻译一句文言文”可能被标为“文言文理解”能力维度和“应用”认知过程；“评价人物做法并说明理由”可能被标为同一语言能力维度和“评价”认知过程。二者不能相互替代。

## 3. 六层操作性定义

| 层级 | 操作性定义 | 典型任务线索 |
| --- | --- | --- |
| 记忆 Remember | 再认、回忆事实、原句、作者或出处 | 默写、背诵、写出原句、作者是 |
| 理解 Understand | 解释、概括、分类或提取材料意义 | 词义解释、信息提取、概括内容、选择符合文意的选项 |
| 应用 Apply | 在具体情境中执行规则、方法或语言转换 | 翻译、断句、修改、根据规则解决情境问题 |
| 分析 Analyze | 分解信息并识别结构、关系、原因或异同 | 分析、比较、论证方法、作用、人物形象 |
| 评价 Evaluate | 根据材料或标准作出判断并提供理由 | 评价、评析、是否赞同、是否合理、谈观点 |
| 创造 Create | 组织要素并生成新的语言作品或方案 | 创作、设计、拟写、续写、仿写、制定方案 |

若一道题同时出现多个认知操作，规则优先标注题目最终要求产出的最高阶主要操作。例如，“分析通知特点并拟写一则新通知”标注为创造，同时保留题型与语言能力字段描述其余特征。

## 4. AI 辅助自动审核流程

1. 读取原始 JSON 和 SQLite，验证材料、题目、答案与来源关联。
2. 根据题干指令词和题型规则识别主要认知过程。
3. 根据材料类别和任务形式标注语言能力维度。
4. 根据原课程带生成二语难度候选，但使用 `candidate` 后缀表示未经实证校准。
5. 为每道题生成 0—4 级通用支架：无提示、任务定向、证据定位、解题策略和答案解析。
6. 记录分类置信度、分类理由和质量标记。
7. 将材料和题目标记为 `ai_reviewed_for_coursework`，表示已完成面向课程作业的自动检查。
8. 保留 `license_status=requires_verification`，避免自动审核被误解为版权授权。

自动标注脚本、规则版本和内容版本均被保存，以支持复现和后续比较。当前规则版本为 `heuristic_v1`，审核方法为 `rule_based_ai_assisted_review_v1`。

## 5. 自动审核字段

每道题保存：

- `bloom_level`：六层认知过程；
- `bloom_confidence`：规则分类置信度；
- `bloom_rationale`：命中的题干线索与分类理由；
- `language_dimension`：主要语言能力维度；
- `question_type`：题型；
- `quality_flags`：选项待结构化、开放题待量规化等潜在问题；
- `scaffold_levels`：0—4 级帮助；
- `review_method`、`label_source` 与 `content_version`：可复现信息。

## 6. 与自动出题的关系

自动出题不直接复制原题。系统先按照学习者水平候选、主题、语言能力维度和布鲁姆层级过滤，再通过向量检索选取少量相似材料和题目作为结构参考。生成模型输出新的材料、题目、答案、解析和支架，并记录参考题 ID、模型版本、提示词版本及与原题的相似度。

六层分类可以作为出题控制变量。例如，系统可对同一阅读材料分别生成信息再认题、意义解释题、情境应用题、结构分析题、观点评价题和文本创作题。对于初级学习者，不要求六层平均分布；系统应依据语言水平控制文本难度，同时依据教学目标选择认知层级。

## 7. 效度边界

当前标注适用于软件原型、课程作业和探索性研究，不等同于专家内容效度审查。关键词规则可能受题干表达、复合任务和隐含认知过程影响。二语难度候选也尚未使用真实学习者数据校准。

后续论文应将本方法描述为“基于规则的 AI 辅助自动标注”，并将其作为研究工具或系统设计的一部分。若需要提出测量学结论，应进一步使用学习者正确率、作答时间、提示次数和题目区分度进行项目分析，或抽取样本进行多标注者一致性检验。
